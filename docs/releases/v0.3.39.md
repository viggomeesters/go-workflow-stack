# v0.3.39 — mandatory root AGENTS.md gateway

Every repository that owns `.go/` state must now carry an exact-case root
`AGENTS.md`. Its versioned managed block acts as the agent entrypoint into the
repository-local source of truth and requires immutable stack freshness,
vision/principles/hierarchy/task reads, validate/status/router, scoped serial
execution, evidence, critic/repair and truthful goal completion.

`init`, `adopt` and `spike` install the gateway. `agents sync` offers an explicit
dry-run/apply repair, while ordinary migration and stack update include the same
bounded operation transactionally. Custom instructions outside the markers,
original newline bytes and file mode are preserved. Ambiguous markers fail
closed. Stack rollback restores the prior root file and casing.

The paired template release is v0.3.18. Focused gateway, full smoke,
standalone-distribution, exact template-pairing and local Linux release gates
must all pass before publication.
