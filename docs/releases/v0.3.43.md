# v0.3.43 — live unattended autonomy proof

This release preserves a real native-Codex campaign that started from a frozen
synthetic pilot and semantic intake, then completed two dependent tasks as
separate local Git releases. The controller was automatically interrupted with
SIGTERM after remote tag `v1.2.0`, waited for the interrupted worker process
group to exit, resumed the same durable campaign and reached `goal_verified`
after publishing `v1.3.0`.

The successful run measured 437.987 seconds and zero human interventions after
launch. Its content-bound manifest verifies the frozen pilot hash, four raw
process records, seeded failure and final behavior, worker profiles, observed
usage, distinct release commits and remote tag readback, clean final Git state,
original-outcome audit and synthetic-only privacy boundary. Six earlier failed
attempts remain visible and motivated fixture hardening around task-independent
test collection, executable intake boundaries, generated caches and process
drain before resume.

The claim is deliberately narrow. This is a short synthetic run on one machine
against a local bare Git remote. It is not an eight-hour production night,
hosted publication, deployment, private consumer mutation, broad repository
benchmark or independent effective-model/billing attestation. GitHub Actions
were not used.
