# v0.3.35 — evidence-backed autonomous intake

This release adds a bounded `intake explore` path that turns rough requests
into source-bound assessments and the smallest independently deliverable `.go`
tasks. It preserves the exact request, source, outcome list, vision and decision
context, then records whether each proposed action creates, reuses or updates
work.

Assessment runs through the existing command or controlled Codex adapters in a
disposable repository copy. The target checkout is read-only during assessment;
the resulting record binds the request, raw assessment, selected model
arguments, usage and materialized task hashes. Reapplying the same intake is an
idempotent no-op, while later feedback can extend matching open work without
losing its original provenance.

Authority remains explicit. Planning and advice intake cannot be claimed for
execution, unresolved questions block only the tasks that reference them, and
unknown bug causes can create research but cannot claim a fix. Decision and
dependency references are validated as lifecycle objects rather than prose.

The existing template v0.3.17 commit remains the immutable compatibility
baseline. Template onboarding for the autonomy campaign remains owned by the
separate `autonomy-template-01` task.
