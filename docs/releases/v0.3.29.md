# v0.3.29 — exact target upgrade previews

Stack update now validates a disposable copy of the complete durable `.go` state
with the resolved annotated target commit before any project update. Explicit
local dependency participants are copied and their paths remapped inside the
preview. Diagnostics retain the original task paths. Failed target validation
prevents pin changes; an older calling validator cannot override a valid target.

Apply recomputes validation and rejects changed project/task/participant data,
changed tag commits and edited plans. Linked workflow inputs and mutating target
validators fail closed. Existing journals and guarded rollback remain supported;
no model, release policy or execution authority is inferred from a pin change.

Verification covers target-only failures, stale/forged inputs, peer isolation,
legacy upgrade/rollback and existing migration contracts. Distribution gates use
ordinary clones and immutable template v0.3.16. This is trusted-runtime validation
isolation, not an operating-system sandbox or a lock against arbitrary editors.
