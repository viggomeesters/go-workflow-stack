# v0.3.46 — repository impact and conformance

This release completes the first repository-intelligence slice. `index blast`
compares a Git baseline with the current worktree, resolves changed source to
stable graph nodes, traverses bounded reverse dependencies, and recommends
linked tests with exact provenance.

When a task opts into `repository_context`, the report compares declared scope
with actual changed components. Advisory policy records findings; strict policy
returns a non-zero status for missing declarations or unsupported changed
paths. The report also compares committed intended dependencies with component
edges observed from resolvable Python imports. These are diagnostic signals:
source, accepted architecture, and tasks remain authoritative.

The command requires a fresh local graph and needs no hosted index, GitHub
Actions, model call, or global workflow state. Roll back by reverting the
release commit and publishing a newer corrective version; do not replace the
immutable tag.
