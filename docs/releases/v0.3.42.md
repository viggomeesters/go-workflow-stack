# v0.3.42 — injected-failure autonomy campaign

One assessed rough request now has a reproducible end-to-end proof through one
controller process, two serial managed task releases and a grounded campaign
goal audit. The fixture uses real subprocesses, disposable Git worktrees and a
local bare remote; the first task is forced through behavioral critic failure
and bounded repair before either release can count as delivered.

An executable coverage manifest binds every claimed failure mode to named tests.
It covers omitted requirements, an unresolved decision beside independent work,
repair no-progress, cumulative budgets, controller loss and foreign ownership,
dirty Git, remote-base movement, lost publication acknowledgement, failed live
readback, cleanup retry and false-green evidence.

The proof is deliberately bounded. Its worker is a deterministic native-protocol
adapter, its release remote is local, and it performs no hosted release,
production deployment, consumer mutation or GitHub Actions run. An actual
unattended live-model night run remains separately owned work.
