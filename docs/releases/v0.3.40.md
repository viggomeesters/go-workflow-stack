# v0.3.40 — outcome-bound campaign goal audit

Campaign completion now depends on the frozen mandate's outcomes, not queue
exhaustion or the mere presence of vision metrics. The shared audit checks exact
task/R# mappings, content-bound verification and critic artifacts, applicable
architecture conformance, hosted releases, and exact deployment readback.

Every outcome is classified as achieved, partial, blocked, or explicitly excluded.
Only achieved/excluded coverage can produce `goal_verified`. Missing-work proposals
remain deduplicated and bounded by the campaign's declared research/repair
allowance, so broader vision proposals cannot silently expand an unattended run.

The controller persists both a schema-validated JSON audit and a compact Markdown
handoff under `.go/runs/campaigns/<campaign-id>/`. The report links original intent,
decisions, tasks, tested candidates, releases, exact live receipts, pending work,
and user decisions with distinct evidence labels.
