# v0.3.44 — repository intelligence foundation

This release makes `.go` the durable entry point to a self-describing
application without turning generated analysis into workflow authority.

Repositories may commit a compact `.go/repository-map.json` containing stable
component IDs, path ownership, intended dependencies, test suites and overlays.
The new `index build` command combines that map with current Git-visible source
to create an ignored local graph. Generic languages receive file, component and
test topology; Python additionally receives symbol and resolvable import edges.

`index status` detects source or map drift and `index query` returns a bounded,
fresh lexical subgraph with exact file, symbol and line provenance. `.go`, VCS
metadata, dependencies, build output and symlinks are excluded. Existing
repositories remain valid without a map, and no hosted provider, embedding
service, database or GitHub Action is introduced.
