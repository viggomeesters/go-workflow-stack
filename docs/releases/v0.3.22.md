# v0.3.22 — resumable configured publication

A managed task with an explicit publication profile can now complete its product
release: build, reserve and prepare version/changelog, verify and review the final
candidate, commit, integrate, create an annotated tag, atomically push, publish,
read back, finish and clean up. A completed task does not report the whole queue done
when blocked work remains. Git-only and GitHub release profiles are supported.

Publication authority is frozen from explicit run arguments, independently of
model selection. Content-bound raw checks and critic evidence must pass before
shipping. Existing release profiles keep their explicit pending handoff unless
publication settings are deliberately configured. Deployment/live service proof
and cross-host transfer remain separate work.

Interrupted effects retain exact intent and reconcile their external result.
Conflicts, unknown responses and live worker groups stop new writes; owned user
files are preserved. Command/time budgets resume the same task and separate
cleanup from publication. Local Git and native-process fixtures exercise complete
release/cleanup, lost acknowledgements, orphan protection and competing writers;
GitHub response fixtures run without external publication. No GitHub Actions.
