# v0.3.16 — explicit model execution

Native Codex phases now enforce the opted-in task model and reasoning effort.
The runtime catalog checks every phase profile before the first worker writes;
review can use an explicit override. Frozen selections prevent hidden changes
between phases. Hermes/custom controlled model execution fails closed while
legacy tasks retain their existing behavior.

Requested settings and independent effective confirmation are separate. This
version reports effective identity as unconfirmed; native JSON events provide
measured token counts when available, and process elapsed time is recorded. No
agent prose is treated as runtime confirmation or invoice evidence.

Verification requires model subprocess tests, existing regressions, make check,
template pairing, distribution installation and the annotated-tag release gate.
The real local catalog is checked; live worker/model-switch proof remains in the
following ABC topology and end-to-end tasks. See docs/agent-adapter-protocol.md.

Rollout is opt-in through execution_contract. Roll back by returning consumers
to the previous immutable stack ref while preserving task, snapshot and evidence
data. Never rewrite a published tag or erase a frozen selection to bypass a gate.
