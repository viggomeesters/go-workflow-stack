# v0.3.18 — durable worker context

Managed native workers receive immutable per-dispatch context references with
current task/project/architecture, Git and workspace identity, checks, concrete
critic feedback, raw file/output evidence and remaining outcomes. Parent and
child bootstrap reject drift before the worker starts. Context is stored once
on disk; legacy adapters keep their existing inline protocol.

Attempt/critic records remain distinct across retries. Explicit task skill and
context files load only for the current phase; notepad prose cannot replace
structured proof. Actual tracked bytes are checked even when index metadata
hides edits. Workspace staging/integration/cleanup now reject such index flags,
repairing a preservation gap in v0.3.17. See docs/agent-adapter-protocol.md.

Verification includes fresh-process context fixtures, model/workspace/schema
regressions, smoke tests, make check, distribution/template pairing and the
annotated-tag gate. Active-task resume remains abc-04; live model-switch proof
remains abc-09/10. No live model or independent model identity is claimed by the
fixture tests.

Rollout is the managed native protocol boundary. Roll back consumers to the
previous immutable ref after stopping workers, preserving canonical snapshots,
registry and worktree content. Do not delete proof or force worktree cleanup to
bypass a drift/ownership gate.
