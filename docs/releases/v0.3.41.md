# v0.3.41 — task-by-task autonomous delivery truth

Serial campaigns now accept a managed task transition only after a read-only
delivery report confirms its approved task lifecycle, complete managed checkpoint,
verified workspace cleanup, and every applicable publication/deployment receipt.
Exact blocker codes distinguish missing authority, unsafe Git state and unknown
external effects. Local completion is never presented as published or live.

The report recognizes operational `.go` closure commits as checkpoint-only when
their product snapshot still equals the released commit. It reuses the durable
publisher and its observe-before-retry reservation rather than duplicating any
release or deployment effect.

An explicit `workspace reconcile` primitive handles a linearly advanced base for
one clean owned workspace. It merges without rewriting history, preserves control
dirt and unrelated worktrees, records both revisions, and invalidates prior checks
and critic evidence. Conflicts abort to the original worker head with bounded path
diagnostics; existing publication intent remains owned by publisher recovery.
