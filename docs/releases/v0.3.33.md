# v0.3.33 — proportionate task design readiness

Tasks with explicit governing decision/brief references now wait for accepted
records even at none/local impact. The legacy autonomous path checks those
prerequisites before starting a builder, matching manual claim and managed runs.
Finish rechecks decisions changed after claim.

The repo-local authoring skill and existing execution context carry one grounded
review rubric: observable behavior, states/edge cases, accepted versus proposed or
delegated choices, real dependencies and evidence tied to original outcomes.
Readiness is a content assessment with reasons and inspected references, not a
schema result, keyword score or new approval flag. An unreproduced bug and useful
investigation notes cannot be represented as a verified correction.

Paired examples cover vague/actionable motion, unresolved rules, delegated timing,
unreproduced bugs, bounded research, a typo and legacy records. Structural tests
explicitly do not claim semantic intelligence. Native context/critic transport is
proved with a deterministic CLI double; no new live model benchmark is claimed.

No schema migration, global skill mutation, new approval system or GitHub Actions.
Unreferenced none/local tasks remain lightweight. Explicit existing unresolved
references intentionally become enforced prerequisites. The immutable template
baseline is v0.3.17; its own v0.3.32 current pin remains a separate relationship.
